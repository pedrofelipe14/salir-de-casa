# salir de casa

Página de la banda y diario del disco en proceso: temas con sus versiones, letras y visuales, diario, archivo de fotos y el instrumento (el plugin Salir de Casa).

Sitio estático (HTML/CSS/JS, sin build). Para verlo, abrí `index.html`.

## Subir contenido

Todo se carga en [`data.js`](data.js): temas (letra, versiones, visuales, fotos), diario, archivo, ideas, links a redes y la info del instrumento. Los archivos van en `assets/`.
